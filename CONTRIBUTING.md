# Contributing

Contributions are welcome via issues and pull requests.

## Setup

```bash
git clone https://github.com/robertazzopardi/wx.git
cd wx
zig build
```

## Development

- Build: `make build` or `zig build`
- Run: `make run` or `zig build run`
- Test: `make test` or `zig build test`

Please add or update tests for any behavior change, and keep pull requests focused on a single change.
